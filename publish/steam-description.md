# 创意工坊页面文案（草稿）

## 标题

观者求解器适配 | Watcher Solver Adapter

## 正文

让**战斗路线求解器**看懂**观者**。

求解器默认会拒绝第三方角色 Mod，装上观者之后会直接停在「检测到不兼容的第三方 Mod」。
装上本 Mod 之后，求解器不但能跑，还能真正理解观者的牌、姿态和额外回合。

**本 Mod 不改变任何游戏行为。** 它只补上求解器缺失的模拟镜像，清单里 `affects_gameplay`
是 `false`。你的牌、伤害、一切数值都和不装它时完全一样 —— 唯一的区别是求解器算得对。

### 需要

- 战斗路线求解器
- 观者
- RitsuLib

三个都要装，缺一个本 Mod 不会加载。

### 覆盖了什么

- **100 张观者卡牌**逐张核对镜像，按反编译出的实现写，不是照着卡面文字猜
- **四种姿态**的进入、退出、伤害倍率和能量收支
- **预视**作为真正的搜索分支：挑哪几张丢由求解器自己搜，不再每次预视都触发一次重算
- **额外回合**（跳跃）、手牌保留、回合开始/结束的各类钩子
- **跨战斗收益**：勤学精进的斩杀升级会被算进长期价值

### 已知缺口

有 8 处效果没有建模。它们**不会静默算错** —— 求解器会在路线上打出红字标明「这里有未镜像的
效果」，你看得见。具体清单在 GitHub 的 README 里。

### 报 Bug

求解器自带问题包导出。导出以后发到 GitHub Issues，附上你看到的现象。
带上问题包我基本都能定位；只有文字描述通常不够。
